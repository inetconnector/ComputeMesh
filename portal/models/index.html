OPENAI DROP-IN INTEGRATION

Jedes Modell mit 2 Zeilen Code ansteuern

Tausche einfach die `base_url` und den `api_key` in deinen bestehenden OpenAI SDKs aus:

inference_example.py 
from openai import OpenAI

client = OpenAI(
    base_url="https://mesh.inetconnector.com/v1",
    api_key="cm_live_your_key"
)

response = client.chat.completions.create(
    model="qwen2.5:7b",
    messages=[{"role": "user", "content": "Schreibe einen Algorithmus für verteiltes Inferenz-Routing."}],
    stream=True
)

for chunk in response:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
